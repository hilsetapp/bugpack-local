# Existing tools I checked

I checked the category before writing the project copy. Similar capture and MCP workflows already exist, so I do not describe Bugpack Local as the first or only tool of its kind.

- [TraceBug](https://tracebug.dev/docs/mcp) documents an offline browser report, local MCP access, session replay, console and network context.
- [BugPack](https://github.com/duhuazhu/BugPack) describes local bug-package creation with an MCP server for coding tools.
- [Bugcap](https://bugcap.io/) describes browser video, console, network, reproduction steps, local exports, and optional upload links.

I am building this repository because I want to work through this specific capture-to-file workflow myself. That is not evidence of an open market or guaranteed demand. Before I spend time on integrations or a store release, I would test whether a QA team wants to use the exported file and MCP reader in its daily work.
